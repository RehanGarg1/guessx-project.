# GuessX

A simple number guessing game written in C.

## How to play

1. Run the program.
2. Choose the difficulty.
3. Enter a number.
4. The program tells you whether your guess is too high or too low.
5. Try to guess the number in as few attempts as possible.

## Features

- Random number generation
- Attempt counter
- High/low hints
- Replay option

## Language

- C
